# Reader-Star v0.0.3

本次版本重点优化了阅读翻页体验。

## Highlights

- 新增右侧阅读区域快捷键：
  - `Space` 下一页
  - `Shift+Space` 上一页
- 当当前章节无法继续翻页时，自动切换到下一章或上一章
- 修复正文与日志模拟区域的滚轮分页体验
- 修复关闭后重新打开时的布局记忆问题

## Installation

- Visual Studio Marketplace
- Install from VSIX: `reader-star.vsix`

## Notes

- 快捷键仅在鼠标停留在右侧阅读区域时生效
- 当前视图名称为“日志”
- 仅支持 TXT 文件
